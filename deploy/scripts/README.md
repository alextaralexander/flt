# deploy/scripts — скрипты развёртывания

Скрипты развёртывания FLT (SYS-11-R1, ADR-011). Репозиторные инструменты проверки
(матрица трассировки, контракты, паритет compose и Helm) сюда не кладутся — они живут
в пакете `src/tools` (`flt_tools`). Каждый скрипт проходит `shellcheck -S warning` (SYS-12-R10).

| Скрипт | Назначение | Решение | Этап |
|---|---|---|---|
| `gen-secrets.sh` | создать `.env` из `deploy/docker-compose/.env.template`; режим `--ci` — одноразовые значения для стендов CI | ADR-013 §3.2 | 1 Г.8 |
| `tls-bootstrap.sh` | первый выпуск сертификата Let's Encrypt для HAProxy | ADR-012 §3.3 | 1 Г.8 |
| `vault-seed-dev.sh` | заполнение Vault в dev-режиме для Helm | ADR-013 §3.3 | 1 Г.8 |
| `deploy.sh` | обновление без простоя на VPS; вызывается `deploy-vps.yml` и вручную | SYS-11-R19 | до первого деплоя на VPS |
| `rollback.sh` | откат на предыдущий тег образов | SYS-11-R20 | до первого деплоя на VPS |
| `backup.sh`, `restore.sh` | резервное копирование и восстановление prod | SYS-11-R18 | до первого деплоя на VPS |
| `flt-compose.sh` | обёртка `docker compose` для пользователя `flt-deploy` | SYS-11-R23 | до первого деплоя на VPS |
| `vps-prepare.sh` | идемпотентная подготовка VPS по чек-листу | SYS-11-R23 | до первого деплоя на VPS |

Секреты скрипты не печатают и не коммитят: значения вводит пользователь или генерирует
`gen-secrets.sh` (ADR-013).
