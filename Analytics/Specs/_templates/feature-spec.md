## 3. Критерии приёмки

- Формат: подзаголовок `### <ID ТЗ>-AC<N> <название>`, затем Given / When / Then. Допускается «And» внутри
  любой части. Given — наблюдаемое начальное состояние (данные, роль, настройки), When — одно действие,
  Then — проверяемый результат: HTTP-ответ, запись в БД, событие Kafka, сообщение WebSocket, состояние экрана.
